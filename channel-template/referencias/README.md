# Referências

Arquivos citados pelos prompts do canal. Cada pasta corresponde a um prompt:

| Pasta | Citada por | Exemplos |
| --- | --- | --- |
| `imagens-ia/` | `imagens-ia.prompt.md` | Imagens que mostram estilo, luz, traço |
| `thumbnails/` | `thumbnail.prompt.md` | Thumbnails aprovadas ou de referência |
| `trilha/` | `trilha.prompt.md` | `links.md` com faixas públicas, amostras próprias |
| `edicao/` | `edicao.prompt.md` | Frames, prints de timeline, links de vídeos |
| `canais/` | `canal.prompt.md` | Prints e notas de canais de referência |

Um arquivo só vale como referência se algum prompt o citar e disser o que ele ensina. Material de terceiros serve para estudo; não entra no vídeo sem licença.
